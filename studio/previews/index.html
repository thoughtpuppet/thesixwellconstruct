Booking Preview Hub

Internal reference only (not linked from the public site). Links marked with ?preview=1 open with dummy data - nothing is read from or written to the live database, and cancel/checkout actions are simulated. Links labelled "Open Live Page" go to the real public pages and behave exactly like they do for clients. Email bodies show the current copy with sample values filled in. Source of truth for emails is functions/api/notifications/_lib.js; editable docs live in docs/email-templates/.

Live Availability Preview (Admin)

To preview the booking page with real schedule data instead of dummy windows, open a submission in the Submissions Console and use its booking preview action - it loads live availability with your admin token and opens /booking/?preview=1 with that data.

Inquiry & Application Forms

Public pages where clients submit inquiries before any approval or booking link exists. On success they redirect to "Inquiry Received" below; on failure they show an inline error and let the client retry. "Open Live Page" links are the real forms - submitting them creates real inquiries. The consultation and build pages also support ?preview=1, which loads dummy calendar windows and disables the Square checkout.

Cancel buttons in previews are simulated - they never touch the live API.
