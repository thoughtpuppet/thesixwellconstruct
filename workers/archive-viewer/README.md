# Archive snapshot viewer Worker

This Worker is the isolated origin for approved historical website snapshots.
It shares the primary site's `SUBMISSIONS_DB` and `SUBMISSION_FILES` bindings,
but exposes only viewer derivatives that pass the complete Archive publication
chain. The browser receives both an iframe sandbox and a response-level CSP
sandbox, so opening a snapshot directly does not remove the isolation boundary.

Public snapshots use:

```text
https://archive-viewer.thesixwellconstruct.com/s/{snapshotId}/{entryPath}
```

Authenticated Studio previews put a token generated by the admin API in a
path prefix. This lets relative CSS, JavaScript, image, font, and media requests
inherit preview access without cookies:

```text
/p/v1.{unixExpiry}.{base64urlHmacSha256}/s/{snapshotId}/{entryPath}
```

The HMAC message is exactly `v1\n{snapshotId}\n{unixExpiry}`. Preview tokens
expire within 15 minutes. Set the shared key separately on both Workers; never
put its value in Git:

```powershell
npx.cmd wrangler secret put ARCHIVE_VIEWER_SIGNING_KEY --config workers/archive-viewer/wrangler.jsonc
```

Validate without deploying:

```powershell
npx.cmd wrangler deploy --dry-run --config workers/archive-viewer/wrangler.jsonc
```
