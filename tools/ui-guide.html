01 · color system

Color

A near-black ground, one warm body ink, one global amber, and nine medium signal colors. Every color has a full-strength signal use and a 25%-opacity dim variant for borders, dividers, and washes.

Adjust these live: hit 🎨 Edit colors in the toolbar (or the button below) to open the inline tuner — tweak any medium's signal color and the brighten/darken steps, watch the swatches above update, then copy the CSS or write it straight back into tokens.css. The editor is hidden when you export the PDF.

Medium signal colors & ramps

Each swatch is a three-stop ramp — dark (signal mixed toward black), the signal color, and bright (mixed toward white) — with the 25% dim variant as the thin strip beneath. Hex labels read dark · signal · bright. These swatches stay in sync with the live tuner.

20% toward white
20% toward black

Sliders set how far the auto bright/dark stops move from each signal. Click a stop swatch to override it by hand; use ↺ to re-derive. The reference swatches above update live.

The medium accent rule (non-negotiable): every medium page must use its own medium color as the primary accent. Never use global amber #FCB867 as the primary signal color on a medium page. Set --venture-color in the page's :root: 
/* in the page's CSS */
:root {
  --venture-color: var(--color-tattooing); /* this medium's token */
}

Then use var(--venture-color) for: filter-chip active states (dot + underline), section labels and kicker text, status indicators, active UI states, and hover border colors on cards and interactive elements. The property is still named --venture-color for legacy compatibility — keep the name.

Source-label badge rule: when a small label names a product source or medium, make the source color a solid badge fill and choose readable ink on top. Do not rely on 10px colored text at reduced opacity for blue, red, or other dark signals on phones.

02 · typography

Typography

Two voices only. Inter 900 for anything declarative — titles, wordmarks, buttons, navigation. Georgia for everything that reads — body copy, labels, captions, metadata. Display gets tighter as it grows; serif labels get wider. Never introduce a third face.

Display--font-display'Inter', Arial, sans-serif — weight 900 (700 at small UI sizes)
Serif--font-serifGeorgia, 'Times New Roman', Times, serif

Four injected, shared pieces — none are hand-written into page HTML. They read body[data-venture] to know where they are.

Breadcrumb (injected)

Construct/ Art.Pill Tattoo House/ Flash

Inter 800 · 10px · 0.16em tracking · uppercase. Links at .58 ink, current page at .38, separators at .28; hover goes amber. Auto-built from the URL path — segment labels come from SECTION_LABELS in construct-wayfinding.js; ap-* slugs render uppercase.

Header band

A fixed 88px frosted band (rgba(14,14,14,.85) + 8px blur + 5px faint bottom border) activates behind the lockup and dots on scroll (#construct-header-shell / .construct-header-active). At ≤640px it grows to 110px and the dot row drops to 92px to clear the wrapped lockup.

Script order on every page, before </body>: transition.js → construct-corner.js → construct-nav.js → construct-wayfinding.js. The data-venture key on <body> must be one of: tattooing | art | merch | about | events | music | writings | archive | film. The attribute name is legacy — do not rename it.

08 · page anatomy

Building a page

The minimum correct skeleton for any new medium or pathway page:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
  <meta name="theme-color" content="#0e0e0e">
  <meta name="color-scheme" content="dark">
  <!-- Inter from Google Fonts: weights 400/500/700/900 -->
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;700;900&display=block">
  <link rel="stylesheet" href="/css/tokens.css">
  <link rel="stylesheet" href="/css/transitions.css">
  <link rel="stylesheet" href="/css/media.css">        <!-- if the page has card grids -->
  <link rel="stylesheet" href="/css/mobile.css">       <!-- mobile guards -->
  <style>
    :root { --venture-color: var(--color-tattooing); } /* THIS medium's color */
  </style>
</head>
<body data-venture="tattooing">   <!-- legacy attr name — required -->
  <main>
    <!-- breadcrumb is injected here automatically -->
    ...
  </main>
  <!-- footer normalized/injected by wayfinding -->
  <script src="/js/transition.js"></script>
  <script src="/js/construct-corner.js"></script>
  <script src="/js/construct-nav.js"></script>
  <script src="/js/construct-wayfinding.js"></script>
</body>
</html>

Edit checklist

  • Root-relative paths only (/css/…, /art/) — the site deploys at the domain root on Cloudflare Workers. No build step; static files + _worker.js.
  • data-venture set correctly on <body> — it drives dot nav highlight, breadcrumb labels, and footer links.
  • --venture-color set to this medium's token — never global amber on a medium page.
  • Use token steps for size, spacing, easing — don't freestyle values between steps.
  • Ecosystem-first: every page points to at least one other medium — a related-medium band, source lineage, or a quiet next action (inquire, claim, read, attend, collect, listen, revisit, enter the archive). Subtle; discovery, not promotion.
  • Mobile pass: collapse grids with minmax(0,1fr); verify at 390px; check hero titles for editor-injected font-size spans.
  • Forms: tattoo/acquisition forms POST multipart/form-data to /api/submissions and include the _gotcha honeypot.
  • Never push — commits are fine; the user always pushes manually. Work directly on main in the main repo (no worktrees).

10 · language rules

Language

Construct vocabulary

SayNotMeaning
mediumnode, ventureTop-level practice area (tattooing, art making, merch…)
pathwaysubnodeEntry route inside a medium (flash, portfolio, inquiry, acquisition…)
the construct—The whole ecosystem; the landing page ring

Legacy technical identifiers keep the old venture name — body[data-venture], --venture-color, Shopify venture: tags. Leave them unless doing a dedicated migration.

Generous language rule

Describe what the work invites, offers, carries, and opens toward. Preferred phrasing: "best for," "drawn toward," "built for," "good entry point," "opens into." Warm boundaries that explain the path forward; process language that helps visitors enter well. Reserve hard boundary phrasing for operational clarity (booking status, legal, confirmations) — and keep even that plain and generous.

Ecosystem-first principle

Every page is a medium in a living ecosystem. When editing any page ask: what is its primary action? Which other mediums should it point toward? Is the connection conceptual, commercial, archival, experiential, or biographical? Connections should feel like discovery — quiet paths, traces, source threads, optional doors — never banner cross-promotion. A conversion page stays focused but carries at least one subtle reminder of the wider construct.

11 · gotchas

Known gotchas

GotchaDetail
Editor-injected font-size spansThe live text editor writes copy edits as inline <span style="font-size: NNpx"> inside hero titles, overriding responsive clamps (a 96px span once made a title's min-content 759px on a 390px phone). A guard in css/mobile.css (≤700px) neutralizes them — but only on pages that link mobile.css. Check for these spans first when a phone layout is cut off.
Bare 1fr mobile collapse1fr can't shrink below child min-content. Always minmax(0, 1fr) in collapse rules. When auditing a cut-off page, check the computed grid track width first.
data-venture is legacyAttribute and --venture-color keep the old name on purpose. Renaming breaks construct-nav, wayfinding, and Shopify tag mapping.
Two .media-grid definitionscss/media.css defines the card grid (auto-fill 260px); css/venture-pages.css also defines a 2-up .media-grid for media panels. Don't load both on one page without checking which wins.
Hidden pagesHiding/showing is done through /tools/page-visibility.html, which edits _worker.js and moves files to .hidden-pages/. Don't hand-move page files.
Token synccss/tokens.css is the palette source. The guide, homepage canvas, and injected dot nav read those variables when served locally. Refresh open pages after saving; use a literal search only for older one-off hardcoded surfaces.
Tiny colored labelsA saturated source color is not automatically legible as small type. Use a solid badge for merch/source labels, with the token color as fill and a computed or chosen readable ink color.
Push policyNever push. The user pushes manually. Work directly on main.
